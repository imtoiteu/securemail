# Secure Mail Mobile — Phase 1 (Android) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an Android Secure Mail companion app that reuses the desktop extension's OpenPGP core unmodified, with native touch UI, encrypted key storage, and share-sheet integration with the Gmail app.

**Architecture:** React Native (Expo) native screens talk over a typed RPC bridge to a hidden WebView ("core host") that runs the **unmodified** `mailvelope/src/modules/*` crypto core against Chromium's WebCrypto. Native holds key custody (Android Keystore → DEK); the WebView performs all cryptography. Storage requests flow back across the bridge to an encrypted blob store.

**Tech Stack:** Expo SDK 57, React Native 0.87.1, react-native-webview 14.0.1, @react-navigation/native 7.3.18, expo-secure-store 57.0.3, expo-local-authentication 57.0.2, expo-file-system 57.0.6, webpack 5, Jest 30, TypeScript (app + bridge), plain ESM JS (core host, to match the desktop core).

**Spec:** `mobile/docs/specs/2026-09-04-android-mobile-design.md` — read it before Task 1. Every task argues from it.

## Global Constraints

- **`mailvelope/` is read-only.** Never write to it. No `grunt`, no `npm ci`, no edits. `grunt prod` begins with `clean` and would destroy `build/chrome/`, the folder users load as an unpacked extension.
- Desktop baseline: branch `internal-stable-v1`, commit `a2bf3bca`. Recorded in `mobile/.desktop-baseline`.
- The crypto core is consumed by **path reference only**: webpack resolves `../../../mailvelope/src/modules/*`. Exactly four modules are swapped via `NormalModuleReplacementPlugin`: `lib/lib-mvelo.js`, `lib/l10n.js`, `lib/analytics.js`, `lib/browser.runtime.js`.
- **No telemetry, ever.** `shims/analytics.js` is a hard no-op. `CLAUDE.md` forbids analytics, remote code loading and third-party trackers.
- **Never weaken private-key or passphrase behavior.** Passphrases live only in the core host's in-memory `chrome.storage.session` shim — never on disk.
- Phase 1 core host has **no network access**. Do not add `fetch` calls, keyserver lookups or WKD.
- Licence: AGPL-3.0. Carry `LICENSE` and `THIRD_PARTY_NOTICES.md` into `mobile/`. Keep upstream Mailvelope GmbH copyright headers on any file derived from upstream.
- `minSdkVersion` 26. Capability is feature-detected at core-host boot (`crypto.subtle`, `ReadableStream`, `TextEncoder`), never assumed from the OS version.
- Main keyring id is the string `` `localhost|mailvelope` `` — import `MAIN_KEYRING_ID` from `mailvelope/src/lib/constants.js`, never hardcode it.
- All user-facing strings come from the i18n layer backed by `mailvelope/locales/{en,vi}/messages.json`. Do not hardcode English in components.
- Commit after every task. Conventional Commits (`feat:`, `test:`, `chore:`).

```bash
#!/usr/bin/env bash
# Asserts the desktop Chrome extension has not been modified.
# REPO_ROOT is the parent of mobile/ — not this script's directory.
set -euo pipefail
HERE="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
REPO_ROOT="$(cd "$HERE/../.." && pwd)"
DESKTOP="$REPO_ROOT/mailvelope"
RELEASE="$DESKTOP/releases/secure-mail-v0.1.3-restored-pink"
fail() { echo "DESKTOP ISOLATION VIOLATED: $1" >&2; exit 1; }

[ -d "$DESKTOP" ] || fail "missing $DESKTOP"

# 1. Working tree clean.
if [ -n "$(git -C "$DESKTOP" status --porcelain)" ]; then
  git -C "$DESKTOP" status --short >&2
  fail "mailvelope/ working tree is dirty"
fi

# 2. HEAD matches the pinned baseline.
expected="$(tr -d '[:space:]' < "$HERE/../.desktop-baseline")"
actual="$(git -C "$DESKTOP" rev-parse HEAD)"
[ "$expected" = "$actual" ] || fail "HEAD is $actual, expected $expected"

# 3. build/chrome/ still matches the released extension checksums.
#    SHA256SUMS.txt paths are relative to the release folder and 161 of them
#    are under extension/, which is byte-identical to build/chrome/.
missing=0; bad=0
while read -r sum path; do
  case "$path" in extension/*) ;; *) continue ;; esac
  target="$DESKTOP/build/chrome/${path#extension/}"
  if [ ! -f "$target" ]; then missing=$((missing+1)); continue; fi
  actual_sum="$(sha256sum "$target" | cut -d' ' -f1)"
  [ "$actual_sum" = "$sum" ] || { echo "  changed: ${path#extension/}" >&2; bad=$((bad+1)); }
done < "$RELEASE/SHA256SUMS.txt"

[ "$missing" -eq 0 ] || fail "$missing file(s) missing from build/chrome/"
[ "$bad" -eq 0 ] || fail "$bad file(s) in build/chrome/ have changed"

echo "OK: mailvelope/ pristine at $actual (161 extension files verified)"
```

```ts
export class RpcError extends Error {

  constructor(message: string, code?: string, name = 'RpcError') {
    super(message);
    this.name = name;
    this.code = code;
  }

export function toShape(err: unknown): RpcErrorShape {
  const e = err as {name?: string; message?: string; code?: string};
  return {
    name: e?.name ?? 'Error',
    message: e?.message ?? String(err),
    code: e?.code
  };
}

  return new RpcError(shape.message, shape.code, shape.name);
```

Create `mobile/packages/bridge/src/client.ts`:

```ts
import {Envelope, Reply, nextId} from './envelope';
import {RpcError, fromShape} from './errors';

type Pending = {resolve: (v: any) => void; reject: (e: Error) => void; timer: ReturnType<typeof setTimeout>};

export function createRpcClient(send: (e: Envelope) => void, opts: {timeoutMs?: number} = {}) {
  const defaultTimeout = opts.timeoutMs ?? 30_000;
  const pending = new Map<string, Pending>();

  function settle(id: string): Pending | undefined {
    const p = pending.get(id);
    if (p) { clearTimeout(p.timer); pending.delete(id); }
    return p;
  }

  return {
    call<T>(method: string, params?: unknown, timeoutMs = defaultTimeout): Promise<T> {
      const id = nextId();
      return new Promise<T>((resolve, reject) => {
        const timer = setTimeout(() => {
          pending.delete(id);
          reject(new RpcError(`${method} timed out after ${timeoutMs}ms`, 'BRIDGE_TIMEOUT'));
        }, timeoutMs);
        pending.set(id, {resolve, reject, timer});
        try {
          send({id, method, params});
        } catch (e) {
          settle(id);
          reject(e as Error);
        }
      });
    },
    handleReply(reply: Reply) {
      const p = settle(reply.id);
      if (!p) return; // late or duplicate reply
      if (reply.ok) p.resolve(reply.result);
      else p.reject(fromShape(reply.error));
    },
    rejectAll(reason: Error) {
      for (const id of Array.from(pending.keys())) settle(id)?.reject(reason);
    }
  };
}
```

Create `mobile/packages/bridge/src/server.ts`:

```ts
import {Envelope, Reply} from './envelope';
import {RpcError, toShape} from './errors';

export type Handlers = Record<string, (params: any) => Promise<unknown>>;

export function createRpcServer(handlers: Handlers, send: (r: Reply) => void) {
  return {
    async handle(env: Envelope): Promise<void> {
      const handler = handlers[env.method];
      if (!handler) {
        send({id: env.id, ok: false,
          error: toShape(new RpcError(`unknown method: ${env.method}`, 'UNKNOWN_METHOD'))});
        return;
      }
      try {
        const result = await handler(env.params ?? {});
        send({id: env.id, ok: true, result: result ?? null});
      } catch (err) {
        send({id: env.id, ok: false, error: toShape(err)});
      }
    }
  };
}
```

```js
/**
 * Minimal chrome.* surface for the Secure Mail core host.
 * Only what mailvelope/src/modules actually calls — verified by grep:
 * storage.local, storage.session, alarms, runtime.getManifest.
 */
const sessionMap = new Map();
const alarmTimers = new Map();
const alarmListeners = [];
let manifest = {version: '0.0.0', oauth2: {client_id: '', scopes: []}};

export function setManifest(m) { manifest = m; }

export function clearSession() {
  sessionMap.clear();
  for (const t of alarmTimers.values()) clearTimeout(t);
  alarmTimers.clear();
}

function pick(map, id) {
  const keys = id === null || id === undefined ? Array.from(map.keys())
    : Array.isArray(id) ? id : [id];
  const out = {};
  for (const k of keys) if (map.has(k)) out[k] = map.get(k);
  return out;
}

export function installChromeShim({storage}) {
  sessionMap.clear();
  alarmTimers.clear();
  alarmListeners.length = 0;

  const local = {
    async get(id) {
      const keys = Array.isArray(id) ? id : [id];
      const out = {};
      for (const k of keys) {
        const v = await storage.get(k);
        if (v !== undefined) out[k] = v;
      }
      return out;
    },
    async set(obj) { for (const [k, v] of Object.entries(obj)) await storage.set(k, v); },
    async remove(id) { for (const k of (Array.isArray(id) ? id : [id])) await storage.remove(k); }
  };

  const session = {
    async get(id) { return pick(sessionMap, id); },
    async set(obj) { for (const [k, v] of Object.entries(obj)) sessionMap.set(k, v); },
    async remove(id) { for (const k of (Array.isArray(id) ? id : [id])) sessionMap.delete(k); },
    async getBytesInUse(id) {
      const picked = pick(sessionMap, id);
      const keys = Object.keys(picked);
      if (!keys.length) return 0;
      return JSON.stringify(picked).length;
    }
  };

  const alarms = {
    create(name, {delayInMinutes = 0} = {}) {
      const existing = alarmTimers.get(name);
      if (existing) clearTimeout(existing.timer);
      const timer = setTimeout(() => {
        alarmTimers.delete(name);
        for (const fn of alarmListeners) fn({name});
      }, delayInMinutes * 60_000);
      alarmTimers.set(name, {timer, name});
    },
    async clear(name) {
      const entry = alarmTimers.get(name);
      if (!entry) return false;
      clearTimeout(entry.timer);
      alarmTimers.delete(name);
      return true;
    },
    async getAll() { return Array.from(alarmTimers.values()).map(({name}) => ({name})); },
    onAlarm: {addListener(fn) { alarmListeners.push(fn); }}
  };

  globalThis.chrome = {
    storage: {local, session},
    alarms,
    runtime: {
      getManifest: () => manifest,
      getURL: path => `core://${path}`,
      // The core never sends runtime messages on mobile; fail loudly if it starts.
      sendMessage: () => { throw new Error('chrome.runtime.sendMessage is not available on mobile'); }
    }
  };
  return globalThis.chrome;
}
```

```js
import {setMessages} from './shims/l10n';
import {buildRegistry} from './registry';
import {makePassphraseProvider} from './passphrase';

export function probeCapabilities() {
  const missing = [];
  if (typeof globalThis.crypto?.getRandomValues !== 'function') missing.push('crypto.getRandomValues');
  if (!globalThis.crypto?.subtle) missing.push('crypto.subtle');
  if (typeof globalThis.TextEncoder !== 'function') missing.push('TextEncoder');
  if (typeof globalThis.ReadableStream !== 'function') missing.push('ReadableStream');
  return {ok: missing.length === 0, missing};
}

/**
 * Boot the core in-process. Transport-free so tests can drive it directly.
 * @param {Object} opts
 * @param {{get,set,remove}} opts.storage  persistent backend (bridge or memory)
 * @param {Function} opts.requestPassphrase  ({keyId,userId,reason}) => Promise<{password,cache}>
 * @param {Function} [opts.log]  uiLog sink
 * @param {Object} opts.manifest
 * @param {Object} opts.messages  locale messages
 */
export async function createCore({storage, requestPassphrase, log = () => {}, manifest, messages}) {
  const probe = probeCapabilities();
  if (!probe.ok) {
    const err = new Error(`unsupported runtime, missing: ${probe.missing.join(', ')}`);
    err.code = 'UNSUPPORTED_RUNTIME';
    throw err;
  }
  installChromeShim({storage});
  setManifest(manifest);
  setMessages(messages);

  // Imported lazily: these pull in the desktop core, which needs chrome.* present.
  const pgpModel = await import('../../../mailvelope/src/modules/pgpModel');
  const keyring = await import('../../../mailvelope/src/modules/keyring');

  await pgpModel.init();
  await keyring.init();

  const ctx = {
    pgpModel,
    keyring,
    log,
    passphrase: makePassphraseProvider({requestPassphrase})
  };
  const handlers = buildRegistry(ctx);

  return {
    async call(method, params = {}) {
      const handler = handlers[method];
      if (!handler) throw new Error(`unknown method: ${method}`);
      return handler(params);
    },
    lock() {
      ctx.passphrase.reset();
      clearSession();
    }
  };
}

export {gpgme} from './shims/browser.runtime';
```

```js
import * as pwdCache from '../../../mailvelope/src/modules/pwdCache';
import * as prefs from '../../../mailvelope/src/modules/prefs';
import {getUserInfo} from '../../../mailvelope/src/modules/key';
import {MvError} from '../../../mailvelope/src/lib/util';

/**
 * Mobile replacement for PwdController (controller/pwd.controller.js).
 * Same decision order as the desktop unlock(): cache hit, then already-decrypted
 * key, then a passphrase we were handed, then ask the user.
 * Requests are serialised so two concurrent operations cannot stack two prompts.
 */
export function makePassphraseProvider({requestPassphrase}) {
  let chain = Promise.resolve();

  async function unlock({key, message, reason = '', noCache = false}) {
    const cacheEntry = await pwdCache.get(key.getFingerprint(), message);
    if (cacheEntry && !noCache) {
      if (cacheEntry.key) return cacheEntry;
      return {key: await pwdCache.unlock({key, password: cacheEntry.password}), password: cacheEntry.password};
    }
    // Mirrors PwdController.keyIsDecrypted() (pwd.controller.js:142).
    if (key.isDecrypted()) {
      return {key, password: undefined};
    }
    const {userId} = await getUserInfo(key, {allowInvalid: true});
    const {password, cache} = await requestPassphrase({
      keyId: key.getKeyID().toHex().toUpperCase(),
      userId,
      reason,
      cache: prefs.prefs.security.password_cache
    });
    if (typeof cache === 'boolean' && cache !== prefs.prefs.security.password_cache) {
      await prefs.update({security: {password_cache: cache}});
    }
    const unlocked = await pwdCache.unlock({key, password, noCache});
    return {key: unlocked, password};
  }

  return {
    unlockKey(options) {
      chain = chain.then(() => unlock(options), () => unlock(options));
      return chain;
    },
    reset() { chain = Promise.resolve(); }
  };
}
```

The already-decrypted check is `key.isDecrypted()`, verified at
`mailvelope/src/controller/pwd.controller.js:142`. Note the desktop guards it
with `&& !options.noCache`; this provider takes the same path because `noCache`
callers reach `pwdCache.unlock` with an explicit password anyway.

```js
  return {
```

```js
      const kr = await keyring.getById(keyringId);
      const defaultKeyFpr = await keyring.getDefaultKeyFpr(keyringId);
      if (!defaultKeyFpr) {
        const err = new Error('No default key set for backup');
        err.code = 'NO_DEFAULT_KEY';

      const {backupCode, message} = await pgpModel.createPrivateKeyBackup(defaultKey, params.keyPwd ?? '');

        throw err;
      }
      return {fingerprint: key.getFingerprint()};
```

```ts
import {createRpcClient, createRpcServer, RpcError, Envelope, Reply, Handlers} from '@securemail/bridge';

type WebViewLike = {injectJavaScript: (js: string) => void};

export class CoreClient {
  private webView: WebViewLike | null = null;
  private rpc = createRpcClient(env => this.post(env), {timeoutMs: 120_000});
  private server = createRpcServer({}, reply => this.postReply(reply));
  private handlers: Handlers = {};

  attach(webView: WebViewLike) { this.webView = webView; }
  detach() { this.webView = null; }

  setHandlers(handlers: Handlers) {
    this.handlers = handlers;
    this.server = createRpcServer(handlers, reply => this.postReply(reply));
  }

  call<T>(method: string, params?: unknown): Promise<T> {
    return this.rpc.call<T>(method, params);
  }

  onCrash() {
    this.rpc.rejectAll(new RpcError('core host crashed or reloaded', 'CORE_CRASHED'));
  }

  async onMessage(event: {nativeEvent: {data: string}}): Promise<void> {
    let msg: any;
    try { msg = JSON.parse(event.nativeEvent.data); } catch { return; }
    if (msg && typeof msg.method === 'string') {
      await this.server.handle(msg as Envelope);
      return;
    }
    if (msg && typeof msg.ok === 'boolean') this.rpc.handleReply(msg as Reply);
  }

  private post(env: Envelope) {
    if (!this.webView) throw new RpcError('core host not attached', 'CORE_NOT_READY');
    this.webView.injectJavaScript(`window.SecureMailCore.handle(${JSON.stringify(env)});true;`);
  }

  private postReply(reply: Reply) {
    if (!this.webView) return;
    this.webView.injectJavaScript(`window.SecureMailCore.reply(${JSON.stringify(reply)});true;`);
  }
}
```

native does custody, the WebView does crypto. `blobStore` therefore only ever
sees opaque bytes, which is exactly what makes it simple to test.

Blob ids are derived by SHA-256 of the storage key so that a key like
`mvelo.keyring.localhost|mailvelope.privateKeys` never becomes a filename.

```ts
import * as SecureStore from 'expo-secure-store';
import * as Crypto from 'expo-crypto';

const DEK_KEY = 'securemail.dek.v1';
let cached: Uint8Array | null = null;

function toB64(bytes: Uint8Array): string {
  let s = ''; for (const b of bytes) s += String.fromCharCode(b);
  return global.btoa ? global.btoa(s) : Buffer.from(bytes).toString('base64');
}
function fromB64(b64: string): Uint8Array {
  const s = global.atob ? global.atob(b64) : Buffer.from(b64, 'base64').toString('binary');
  const out = new Uint8Array(s.length);
  for (let i = 0; i < s.length; i++) out[i] = s.charCodeAt(i);
  return out;
}

export async function loadDek(): Promise<Uint8Array | null> {
  if (cached) return cached;
  const stored = await SecureStore.getItemAsync(DEK_KEY);
  if (!stored) return null;
  cached = fromB64(stored);
  return cached;
}

export async function getOrCreateDek(): Promise<Uint8Array> {
  const existing = await loadDek();
  if (existing) return existing;
  const fresh = Crypto.getRandomBytes(32);
  await SecureStore.setItemAsync(DEK_KEY, toB64(fresh), {
    keychainAccessible: SecureStore.WHEN_UNLOCKED_THIS_DEVICE_ONLY
  });
  cached = fresh;
  return fresh;
}

/** Drop the in-memory copy. Called on relock; does not delete the stored DEK. */
export function clearDekCache(): void {
  if (cached) cached.fill(0);
  cached = null;
}

/** Destroys the DEK permanently. Every stored blob becomes unreadable. */
export async function destroyDek(): Promise<void> {
  clearDekCache();
  await SecureStore.deleteItemAsync(DEK_KEY);
}
```

```ts
/** Storage keys contain '|' and '.', so hash them into safe filenames. */
async function fileFor(id: string): Promise<string> {

      {encoding: FileSystem.EncodingType.Base64});

  } catch { return null; }
}

export async function removeBlob(id: string): Promise<void> {
  await ensureDir();
  await FileSystem.deleteAsync(await fileFor(id), {idempotent: true}).catch(() => {});
```

```js
function makeEncryptedStorage(outbound, getDek) {
  const enc = new TextEncoder(); const dec = new TextDecoder();
  async function keyFor() {
    return crypto.subtle.importKey('raw', getDek(), 'AES-GCM', false, ['encrypt', 'decrypt']);
  }
  return {
    async get(id) {
      const b64 = await outbound.call('storage.get', {id});
      if (!b64) return undefined;
      const raw = Uint8Array.from(atob(b64), c => c.charCodeAt(0));
      const iv = raw.slice(0, 12);
      const plain = await crypto.subtle.decrypt({name: 'AES-GCM', iv}, await keyFor(), raw.slice(12));
      return JSON.parse(dec.decode(plain));
    },
    async set(id, obj) {
      const iv = crypto.getRandomValues(new Uint8Array(12));
      const ct = new Uint8Array(await crypto.subtle.encrypt(
        {name: 'AES-GCM', iv}, await keyFor(), enc.encode(JSON.stringify(obj))));
      const packed = new Uint8Array(iv.length + ct.length);
      packed.set(iv); packed.set(ct, iv.length);
      let s = ''; for (const b of packed) s += String.fromCharCode(b);
      return outbound.call('storage.set', {id, obj: btoa(s)});
    },
    remove: id => outbound.call('storage.remove', {id})
  };
}
```

```ts
import * as LocalAuthentication from 'expo-local-authentication';

/** Pure so it is testable without timers or AppState. */
export function shouldRelock(backgroundedAt: number | null, now: number, graceMs: number): boolean {
  if (backgroundedAt === null) return false;
  return now - backgroundedAt >= graceMs;
}

export async function authenticate(): Promise<{ok: boolean; reason?: string}> {
  const hasHardware = await LocalAuthentication.hasHardwareAsync();
  if (!hasHardware) return {ok: true}; // no biometric hardware: the DEK still gates access
  const result = await LocalAuthentication.authenticateAsync({
    promptMessage: 'Unlock Secure Mail',
    disableDeviceFallback: false, // allow device PIN when biometrics are unenrolled
    cancelLabel: 'Cancel'
  });
  return result.success ? {ok: true} : {ok: false, reason: (result as any).error};
```

```ts
export const MIN_PASSPHRASE_LENGTH = 12;

export function validateIdentity({fullName, email}: {fullName: string; email: string}) {
  const errors: Record<string, string> = {};
  if (!fullName.trim()) errors.fullName = 'keygen_error_name_required';
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email.trim())) errors.email = 'keygen_error_email_invalid';
  return {ok: Object.keys(errors).length === 0, errors};
}

export function validatePassphrase(pass: string, confirm: string) {
  const errors: Record<string, string> = {};
  if (pass.length < MIN_PASSPHRASE_LENGTH) errors.passphrase = 'keygen_error_passphrase_short';
  if (pass !== confirm) errors.confirm = 'keygen_error_passphrase_mismatch';
  const classes = [/[a-z]/, /[A-Z]/, /\d/, /[^A-Za-z0-9]/].filter(re => re.test(pass)).length;
  const strength = pass.length >= 20 || classes >= 3 ? (pass.length >= 24 ? 'strong' : 'fair') : 'weak';
  return {ok: Object.keys(errors).length === 0, errors, strength} as const;
}
```

```ts
  if (!fpr) return '';
  return (fpr.toUpperCase().match(/.{1,4}/g) ?? []).join(' ');
}

export function keyStatusLabel(key: any): {label: string; tone: 'ok' | 'warn' | 'error'} {
  if (key.validity === false) return {label: 'key_status_invalid', tone: 'error'};
  if (key.exDate && new Date(key.exDate).getTime() < Date.now()) {
    return {label: 'key_status_expired', tone: 'error'};
  }
  if (key.exDate) return {label: 'key_status_expires', tone: 'warn'};
  return {label: 'key_status_valid', tone: 'ok'};
}

/** Input is the output of the `keyring.getKeys` RPC, i.e. mapKeys() rows. */
export function toKeyRows(keyList: any[], defaultFpr: string) {
  return keyList.map(k => ({
    fingerprint: k.fingerprint,
    title: k.name || k.userId || k.email,
    subtitle: k.email,
    badge: k.type === 'private' ? 'key_badge_private' : 'key_badge_public',
    isDefault: k.fingerprint === defaultFpr,
    status: keyStatusLabel(k)
  }));
}
```

- [ ] **Step 3: Write pgpText.ts**

```ts
type Kind = 'message' | 'signed' | 'publicKey' | 'privateKey' | 'none';

const PATTERNS: Array<{kind: Kind; re: RegExp}> = [
  {kind: 'signed', re: /-----BEGIN PGP SIGNED MESSAGE-----[\s\S]*?-----END PGP SIGNATURE-----/},
  {kind: 'privateKey', re: /-----BEGIN PGP PRIVATE KEY BLOCK-----[\s\S]*?-----END PGP PRIVATE KEY BLOCK-----/},
  {kind: 'publicKey', re: /-----BEGIN PGP PUBLIC KEY BLOCK-----[\s\S]*?-----END PGP PUBLIC KEY BLOCK-----/},
  {kind: 'message', re: /-----BEGIN PGP MESSAGE-----[\s\S]*?-----END PGP MESSAGE-----/}
];

export function detectPgpBlock(text: string): {kind: Kind; block: string | null} {
  for (const {kind, re} of PATTERNS) {
    const m = text.match(re);
    if (m) return {kind, block: m[0]};
  }
  return {kind: 'none', block: null};
}

export function routeSharedText(text: string): {screen: 'Decrypt' | 'ImportKey' | 'Encrypt'; payload: string} {
  const {kind, block} = detectPgpBlock(text);
  if (kind === 'message' || kind === 'signed') return {screen: 'Decrypt', payload: block!};
  if (kind === 'publicKey' || kind === 'privateKey') return {screen: 'ImportKey', payload: block!};
  return {screen: 'Encrypt', payload: text};
}
```

Signed messages are checked before the others because a clearsigned block
contains `BEGIN PGP SIGNATURE`, which a naive `message` match would not catch but
a reordered list could misclassify.
